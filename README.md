# Парсер школ России по открытым данным

Сбор сведений обо всех действующих (открытых) общеобразовательных организациях
России из официальных открытых источников.

Собираемые поля: **ИНН, КПП, ОГРН, краткое и полное наименование, юридический
адрес (регион / город / населённый пункт / улица), e-mail, телефоны, сайт,
должность и ФИО руководителя, численность работников, ОКВЭД, статус.**

## Законность

Используются только открытые данные:

| Источник | Что даёт | Правовое основание |
|---|---|---|
| [ЕГРЮЛ ФНС России](https://egrul.nalog.ru) — поиск и официальная выписка | ИНН, КПП, ОГРН, наименования, юридический адрес, руководитель (должность + ФИО), ОКВЭД, статус | п. 1 ст. 6 ФЗ № 129-ФЗ: сведения ЕГРЮЛ открыты и общедоступны |
| [Открытые данные ФНС](https://www.nalog.gov.ru/opendata/7707329152-sshr2019/) — «Сведения о среднесписочной численности работников» | численность работников | ст. 102 НК РФ (не является налоговой тайной), опубликовано как открытые данные |
| [ГИС ГМУ bus.gov.ru](https://bus.gov.ru) | e-mail, телефон, сайт учреждения | официальный открытый реестр государственных и муниципальных учреждений |
| [OpenStreetMap](https://overpass-api.de) | телефон, e-mail, сайт | лицензия ODbL |
| Официальные сайты школ, раздел «Сведения об образовательной организации» | e-mail, телефон | ст. 29 ФЗ № 273-ФЗ и ПП РФ № 1802 — обязательная публикация |

Капча не обходится, платные API и закрытые данные не используются, частота
запросов ограничена (по умолчанию ~1 запрос в секунду).

## Установка

```bash
pip install requests            # обязательное
pip install openpyxl            # для выгрузки в XLSX
apt-get install poppler-utils   # pdftotext — разбор выписок ЕГРЮЛ
```

## Использование

```bash
# 1. Поиск школ в ЕГРЮЛ (по всем 89 регионам и вариантам наименования)
python3 -m ru_schools.cli discover

# только по отдельным регионам
python3 -m ru_schools.cli discover --regions 77 78 50

# 2. Официальные выписки из ЕГРЮЛ: адрес, ОКВЭД, руководитель
python3 -m ru_schools.cli details --workers 2

# 3. Численность работников из открытых данных ФНС (архив ~100 МБ)
python3 -m ru_schools.cli staff

# 4. Контакты (e-mail, телефоны)
python3 -m ru_schools.cli contacts --providers busgov osm

# 5. Выгрузка
python3 -m ru_schools.cli export --csv data/schools.csv --xlsx data/schools.xlsx

# всё сразу
python3 -m ru_schools.cli run
```

### Сбор до победного

`watchdog.sh` держит сбор запущенным, пока не будет собрано всё: гоняет
`run_collect.sh` по кругу, переживает недоступность сервиса и падения,
поднимает процесс заново и останавливается только когда появляется
`data/COLLECT_DONE`.

```bash
setsid nohup ./watchdog.sh > data/watchdog.log 2>&1 < /dev/null &

python3 -m ru_schools.cli todo   # осталось: поиск, выписки, контакты
tail -f data/collect.log
```

По ходу дела скрипт выгружает CSV/JSONL и коммитит их, а раз в 20 000
выписок сохраняет сжатый снимок базы `data/state.sql.gz`. На чистой машине
сбор продолжается с этого места:

```bash
python3 -m ru_schools.cli restore   # база из снимка
setsid nohup ./watchdog.sh > data/watchdog.log 2>&1 < /dev/null &
```

Состояние хранится в SQLite (`data/schools.db`), поэтому любой этап можно
прервать и запустить заново — работа продолжится с места остановки.
Скорость регулируется флагом `--rate` (запросов в секунду).

```bash
python3 -m ru_schools.cli stats     # прогресс по базе
python3 -m ru_schools.cli regions   # коды регионов
```

## Как это работает

1. **discover** — поиск ЕГРЮЛ по 13 вариантам наименования («средняя
   общеобразовательная школа», «гимназия», «лицей», «школа-интернат», …)
   в разрезе каждого региона; постраничный обход выдачи. Организации с
   заполненной датой прекращения деятельности отбрасываются — остаются
   только открытые.
2. **details** — по каждой организации заказывается официальная выписка из
   ЕГРЮЛ в PDF, текст разбирается по колонкам таблицы выписки. Отсюда
   юридический адрес, точная должность и ФИО руководителя, ОКВЭД.
   Школами считаются организации с ОКВЭД 85.12 / 85.13 / 85.14 (начальное,
   основное и среднее общее образование); автошколы, музыкальные, спортивные
   школы и школы искусств отсеиваются.
3. **staff** — архив открытых данных ФНС сопоставляется по ИНН.
4. **contacts** — источники перебираются по очереди, первый непустой ответ
   побеждает; недоступный источник пропускается.
5. **export** — CSV (разделитель `;`, UTF-8 BOM — открывается в Excel),
   JSONL и XLSX.

## Структура

```
ru_schools/
  cli.py          командный интерфейс
  pipeline.py     этапы сбора
  egrul.py        клиент ЕГРЮЛ (поиск, выписка)
  vypiska.py      разбор PDF-выписки
  sshr.py         численность работников (открытые данные ФНС)
  contacts.py     провайдеры контактов
  store.py        SQLite-хранилище
  export.py       выгрузка CSV / JSONL / XLSX
  regions.py      коды регионов
```

## Ограничения

* **Численность** — это среднесписочная численность *работников*, а не число
  учащихся: количество учеников в открытых данных ФНС и ЕГРЮЛ отсутствует.
  При этом набор ФНС «Сведения о среднесписочной численности работников»
  практически целиком состоит из коммерческих организаций (ООО и т.п.):
  государственные и муниципальные учреждения в него почти не попадают, так
  что для школ это поле заполняется редко. Полные данные о штатной
  численности учреждений публикует ГИС ГМУ (bus.gov.ru).
* **Один ИНН — одно юридическое лицо.** Школы, присоединённые к
  образовательным комплексам, отдельного ИНН не имеют и в реестре
  представлены головной организацией.
* **Контакты** заполняются не для всех школ: ЕГРЮЛ телефонов и e-mail не
  содержит, а полнота внешних открытых источников различается по регионам.
* ФНС ограничивает частоту запросов; при слишком высоком `--rate` сервис
  отвечает 403/405 — клиент это переживает, но сбор замедляется.
