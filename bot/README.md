# DIYORDE Store — Telegram-бот

Копия магазина подписок @diyordestorebot на Python (python-telegram-bot 21).

## Что умеет

**Главное меню** (reply-клавиатура): 🛍 Купить · 👤 Мой профиль · 💻 Инструкции · 📰 Новости · 🧑‍💻 Тех.Поддержка.

**Покупка**: Купить → «Подписки DDE Store» → список тарифов (Месяц 790₽, 3 Месяц 1490₽,
6 Месяц 2490₽) → карточка товара с остатком, счётчиком количества (±1 / ±10 / ±100),
кнопками «Купить за N₽», «Есть промокод», «Поделиться», «‹ Назад».

**Заказ**: номер вида `N1PHFR28L`, сумма, таймер на 15 минут с дедлайном по МСК,
оплата с баланса или через PayPalych (СБП), кнопка отмены. Коды резервируются на складе
при создании заказа и возвращаются обратно при отмене или просрочке.

**Профиль**: баланс, число покупок, «Мои покупки» с выданными кодами активации,
пополнение баланса.

**Админ**: `/admin`, `/stats`, `/addstock`, `/addpromo`, `/balance`, `/paid`.

## Запуск

```bash
cd bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и ADMIN_IDS
python main.py
```

База данных SQLite создаётся автоматически, тарифы засеиваются при первом запуске.

## Наполнение склада

Коды активации добавляет админ одним сообщением:

```
/addstock dde_1m
DDE-AAAA-1111
DDE-BBBB-2222
```

Остаток по каждому тарифу виден в `/admin` и в карточке товара («Кол-во: N шт»).

## Промокоды

```
/addpromo SALE10 10 100    # код, скидка в %, лимит применений (0 — без лимита)
```

Пользователь вводит код по кнопке «🎟 Есть промокод», скидка применяется к сумме заказа.

## Оплата

* **С баланса** — списание сразу, коды выдаются мгновенно.
* **PayPalych • СБП** — работает при заданных `PAYPALYCH_TOKEN` и `PAYPALYCH_SHOP_ID`:
  бот создаёт счёт, даёт ссылку и кнопку «Проверить оплату». Без ключей кнопка
  сообщает, что онлайн-оплата недоступна.
* **Вручную** — админ подтверждает оплату командой `/paid N1PHFR28L`.
